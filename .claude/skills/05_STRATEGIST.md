## 2. 수익 모델 v2 (확정)

### 2.1 링크 개수 정책

| 구분 | 링크 개수 | 조건 |
|------|----------|------|
| **무료 기본** | 2개 | - |
| **공유 보상** | +1개 (총 3개) | 친구 초대 → 친구 가입 시 |
| **프리미엄** | 무제한 | 월 $2.99 / 평생 $29.99 |

### 2.2 추가 알림 시간 정책

| 구분 | 추가 시간 | 조건 |
|------|----------|------|
| **무료** | 광고 시청 시 +1개 | 링크당, 횟수 제한 없음 |
| **프리미엄** | 무제한 | 광고 없이 바로 추가 |

```
예시: "아침 스트레칭" 링크
├─ 기본: 07:00 (1개, 무료)
├─ 추가: 10:00 (광고 시청)
├─ 추가: 15:00 (광고 시청)
└─ 추가: 20:00 (광고 시청)

→ 1개 링크에 4번 알림 = 광고 3회 시청
```

### 2.3 왜 이 모델인가?

```
✅ 무료 유저
- 핵심 기능 사용 가능 (링크 2개, 각 1번 알림)
- 광고 보면 더 많이 사용 가능
- "못 쓰겠다" 느낌 없음

✅ 광고 수익
- 보상형 광고 = 배너의 10-30배 CPM
- 유저가 자발적으로 시청 (거부감 낮음)
- 파워 유저일수록 많이 시청

✅ 프리미엄 전환
- "매번 광고 보기 귀찮아" → 프리미엄
- 자연스러운 업셀 유도
```

### 2.4 수익 시뮬레이션

#### 기존 모델 (MAU 10,000명)
```
배너 광고: ~$300/월
프리미엄 전환: 3% (300명 × $5 평균) = ~$200/월
총 수익: ~$500/월
```

#### 새 모델 (MAU 10,000명)
```
배너 광고: ~$150/월 (노출 감소)
보상형 광고: ~$600/월 (유저당 월 6회, eCPM $10)
프리미엄 전환: 5% (500명 × $6 평균) = ~$400/월
총 수익: ~$1,150/월 (+130%)
```

## 3. 시장 분석

### 3.1 경쟁 앱 분석

| 앱 | 핵심 기능 | 가격 | 약점 |
|----|----------|------|------|
| **알라미** | 알람 + 미션 | $4.99/월 | 링크 알림 없음 |
| **Pocket** | 링크 저장 | $4.99/월 | 알림 없음, 소셜 없음 |
| **Habitify** | 습관 트래커 | $6.99/월 | 링크 연동 없음 |
| **Fabulous** | 루틴 앱 | $12.99/월 | 고가, 복잡함 |

### 3.2 LinkPing 포지셔닝
```
                  알림 기능
                     ↑
         알라미      │     LinkPing ★
                     │     (알림 + 소셜 + 링크)
    ─────────────────┼─────────────────→ 소셜 기능
                     │
         Pocket      │     Habitify
      (저장만)       │     (습관만)
```

### 3.3 차별화 포인트
1. **링크 + 알림** 조합 (Pocket에 없음)
2. **소셜 동기부여** (알라미에 없음)
3. **고정 알람 투표** (유니크 기능)
4. **전화 알람** (tel: URL 지원) - 행동 유도형 알람
5. **저렴한 가격** ($2.99 vs 경쟁사 $5-13)

### 3.4 전화 알람: 새로운 시장 기회

```
기존 알람앱:  "일어나!" → 기상 목적
LinkPing:    "행동해!" → 실제 행동 유도

전화 알람 = "행동해" 철학의 극대화
```

**핵심 차별점**: 다른 앱들은 "링크를 열어줌". LinkPing은 "전화를 걸게 함".

```
알라미, 알람몬: 기상 알람 (미션으로 깨우기)
Pocket, Instapaper: 링크 저장 (나중에 읽기)
LinkPing: 행동 알람 (링크 열기 + 전화 걸기)
```

## 11. 전화 알람 기능 (신규)

### 11.1 기능 개요

```
기존: URL 링크 → 알림 → 탭 → 브라우저/앱 열림
신규: tel: URL → 알림 → 탭 → 전화 앱 열림 (바로 통화)

예시:
- "제이슨에게 전화" → tel:010-1234-5678 → 11시 알림 → 탭 → 전화 연결
```

### 11.2 핵심 Use Cases

| 타겟 | 상황 | 예시 |
|------|------|------|
| **연인** | 매일 안부 전화 | "오늘도 여자친구한테 전화했나요?" |
| **직장인** | 부모님 안부 | "효도 알람 - 매일 밤 10시 어머니께" |
| **자녀** | 어르신 안부 | "독거 어르신 안부 체크" |
| **친구** | 정기 연락 | "오래된 친구에게 연락하기" |
| **비즈니스** | 클라이언트 팔로업 | "고객 팔로업 전화 리마인더" |

### 11.3 기술 구현

```
✅ 구현 완료:
1. tel: URL 스킴 지원
2. 전화번호 유효성 검사
3. 내 번호 저장 (프로필)
4. 내 번호 = 전화 안 걸림 (자기 자신 방지)
5. 국제 전화번호 정규화 (+82 → 0)

동작 흐름:
알림 도착 → 유저 탭 →
├─ 상대방 번호 → 전화 앱으로 바로 연결
└─ 내 번호 → 전화 안 걸림 (앱만 열림)
```

### 11.5 전화 알람 마케팅 전략

#### 바이럴 시나리오
```
1. "효도 알람" 콘텐츠
   - "부모님께 매일 전화하기로 했는데 자꾸 까먹으시죠?"
   - "링크핑이 대신 알려드릴게요 📞"
   - 타겟: 20-30대 직장인 (부모님과 따로 사는)

2. "연인 알람" 콘텐츠
   - "오늘도 연락 깜빡했다고 혼났어요? 😅"
   - "링크핑으로 자동 리마인더 설정하세요"
   - 타겟: 20대 커플, 장거리 연애

3. "기억의 전화" 콘텐츠
   - "바쁘다는 핑계로 연락 못한 친구가 있나요?"
   - "주 1회 친구에게 전화하기"
   - 타겟: 30-40대 직장인
```

#### SNS 콘텐츠 아이디어
```
틱톡/릴스:
- "효도 알람 설정하는 법" (튜토리얼)
- "남친한테 매일 전화하게 해주는 앱" (연인)
- "엄마한테 전화하라는 알람이 울렸다" (일상)

트위터/X:
- "부모님한테 전화한 지 며칠 됐어요?
   저는 링크핑 효도 알람 덕분에 매일 해요"
```

### 11.6 타겟 확장

```
기존 타겟: 20-40대 직장인/학생 (운동, 자기계발)
    ↓
확장 타겟:
├─ 20대: 연인 전화, 부모님 안부
├─ 30대: 부모님 안부, 친구 연락
├─ 40대: 부모님 안부 (효도), 자녀 체크인
└─ 50대+: 손주 연락, 친구 안부

핵심: "소중한 사람과 연결되세요"
```
