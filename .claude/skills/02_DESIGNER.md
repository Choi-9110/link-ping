## 4. 알림 센터 UI

### 4.1 알림 목록 화면
```
┌─────────────────────────────────┐
│  ← 알림             [모두 읽음]  │
├─────────────────────────────────┤
│                                 │
│  ┌─────────────────────────┐   │
│  │ 💗 응원 핑               │   │
│  │   "운동하는민수님이       │   │
│  │    응원을 보냈어요!"      │   │
│  │   🔗 아침 스트레칭   5분전 │   │
│  └─────────────────────────┘   │
│                                 │
│  ┌─────────────────────────┐   │
│  │ 🔵 시간 수정 요청        │   │ ← 투표 UI
│  │   "운동하는민수님이       │   │
│  │    시간을 09:00→10:00     │   │
│  │    수정 요청했어요"       │   │
│  │                           │   │
│  │   [거절]      [승인]      │   │ ← 버튼
│  │   24시간 내 응답하지 않으면 │   │
│  │   알람이 OFF됩니다        │   │
│  └─────────────────────────┘   │
│                                 │
└─────────────────────────────────┘
```
