## 1. 앱 개요

### 앱 이름
**LinkPing** (링크핑)

### 한 줄 설명
저장한 링크를 정해진 시간에 알려주고, 친구와 함께 실천하는 앱

### 슬로건
- "혼자 말고, 같이 하자"
- "Your Accountability Partner for Saved Links"

### 핵심 가치
```
1. 저장한 콘텐츠를 실제로 보게 만들기
2. 친구와 함께 = 실천율 95% (혼자는 10%)
3. 고정 알람으로 함께 하는 습관 만들기
```

## 3. 고정 알람 투표 시스템 상세

### 3.1 개요
고정 알람(isLocked=true)을 공유받은 사용자들이 함께 시간을 관리하는 시스템

### 3.2 삭제 시나리오
```
생성자가 고정 알람 삭제
    ↓
저장한 모든 사용자에게 알림 발송
"'닉네임'님이 링크알람을 삭제하였습니다.
 기존의 '타이틀' 링크가 삭제되었습니다."
```

### 3.3 수정 시나리오
```
생성자가 시간 수정 요청
    ↓
저장한 모든 사용자에게 투표 알림
    ↓
24시간 내 투표 (승인/거절)
    ↓
┌─ 50% 이상 승인 → 전체 수정 적용
│   └─ 거절한 사람 → 알람 OFF + "거절하셨기 때문에 해당 알람은 OFF되었습니다"
│
└─ 50% 미만 승인 → 수정 거부
    └─ 생성자에게 "수정이 거부되었습니다" 알림

24시간 무응답자 → 알람 OFF + "시간이 지났습니다" 알림
```

### 3.4 알림 타입 (PingType)
| 타입 | 설명 |
|------|------|
| cheer | 응원 핑 |
| tease | 약올리기 핑 |
| inquiryReply | 문의 답변 |
| linkDeleted | 고정 알람 삭제됨 |
| modificationRequest | 시간 수정 요청 (투표) |
| modificationApproved | 수정 승인됨 (전체) |
| modificationRejected | 수정 거부됨 (전체) |
| modificationApplied | 수정 적용됨 (거절했지만 전체 승인) |

## 4. 이모지 아바타 시스템

### 4.1 개요
가벼운 프로필 커스터마이징을 위한 이모지 선택 시스템

### 4.2 이모지 카테고리 (64종)
```
얼굴: 😀 😊 🥰 😎 🤓 🤪 🥳 😇
동물: 🐶 🐱 🐰 🦊 🐻 🐼 🐨 🦁
음식: 🍎 🍊 🍋 🍉 🍇 🍓 🍒 🥑
활동: ⚽ 🏀 🎾 🎮 🎨 🎸 📚 💻
```

### 4.3 저장 위치
- 회원: Firestore `users/{uid}/profileEmoji`
- 게스트: Hive `settings/guestEmoji`

### 4.4 동기화
- 이모지 변경 시 `sharedLinks`의 `savedByUsers`도 업데이트
- 다른 사용자가 볼 때 최신 이모지 표시

## 5. 수익 모델 v2 (확정)

### 5.1 링크 개수 정책
| 구분 | 링크 개수 | 조건 |
|------|----------|------|
| **무료 기본** | 2개 | - |
| **공유 보상** | +1개 (총 3개) | 친구 초대 → 친구 가입 시 |
| **프리미엄** | 무제한 | 월 $2.99 / 평생 $29.99 |

### 5.2 추가 알림 시간 정책
| 구분 | 추가 시간 | 조건 |
|------|----------|------|
| **무료** | 광고 시청 시 +1개 | 링크당, 횟수 제한 없음 |
| **프리미엄** | 무제한 | 광고 없이 바로 추가 |

```
예시: "아침 스트레칭" 링크
├─ 기본: 07:00 (1개, 무료)
├─ 추가: 10:00 (광고 시청)
├─ 추가: 15:00 (광고 시청)
└─ 추가: 20:00 (광고 시청)

→ 1개 링크에 4번 알림 = 광고 3회 시청
```

### 5.3 가격 정책
| 옵션 | 가격 | 비고 |
|------|------|------|
| 월간 구독 | $2.99/월 | 유지 |
| 연간 구독 | $9.99/년 | **신규** (월 $0.83) |
| 평생 구매 | $29.99 | $19.99에서 인상 |

### 5.4 수익 예상 (MAU 10,000명)
```
배너 광고: ~$150/월
보상형 광고: ~$600/월 (유저당 월 6회, eCPM $10)
프리미엄 전환: 5% (500명 × $6 평균) = ~$400/월
총 수익: ~$1,150/월
```
