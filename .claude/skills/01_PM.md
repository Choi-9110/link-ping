## 1. 앱 개요

### 앱 이름
**LinkPing** (링크핑)

### 한 줄 설명
저장한 링크를 정해진 시간에 알려주고, 친구와 함께 실천하는 앱

### 슬로건
- 🇰🇷 한국: **"혼자 말고, 같이 하자"**
- 🌍 해외: **"Your Accountability Partner for Saved Links"**

### 핵심 가치
```
1. 저장한 콘텐츠를 실제로 보게 만들기
2. 친구와 함께 = 실천율 95% (혼자는 10%)
3. 앱 내 채팅 X → 외부 연락 유도 (카톡, iMessage 등)
```

## 2. 문제 정의

### 타겟 사용자
```
Primary: 20-40대 직장인/학생 (글로벌)
- 인스타, 틱톡, 유튜브 자주 사용
- 운동/자기계발 영상 저장만 하고 안 봄
- "Accountability Partner" 필요성 인식

Secondary: 운동/습관 커뮤니티
- 같이 운동할 친구 찾는 사람
- 온라인 스터디/챌린지 참여자
```

### 해결하려는 문제
```
😤 Pain Point:
1. "저장한 운동 영상, 한 번도 안 봤어"
2. "혼자 하려니까 작심삼일"
3. "친구랑 같이 하고 싶은데 방법이 없어"

💡 Solution:
- 저장한 링크 + 알림 시간 설정
- 친구 초대 → 같은 링크 공유
- "N명이 같이 하는 중" → 동기부여
- "너 했어?" "나 했어 ㅋㅋ" → 외부 대화 유도
```

## 3. 핵심 기능 (MVP v1.0)

### 기능 목록

| # | 기능 | 설명 | 우선순위 |
|---|------|------|----------|
| 1 | **회원가입** | 소셜 로그인 + 닉네임 + 국가 | Must Have |
| 2 | **링크 등록** | URL + 메모 + 알림시간 설정 | Must Have |
| 3 | **알림 & 이동** | 푸시 알림 → 원클릭 링크 이동 | Must Have |

| 5 | **공유로 받기** | 다른 앱에서 공유 → 바로 저장 | Must Have |
| 6 | **저장 인원 표시** | "이 링크를 N명이 저장" | Must Have |
| 7 | **친구 초대** | 링크 공유로 친구 초대 | Should Have |

### 제외 기능 (v2에서 고려)
```
❌ 이번에 안 함:
- 닉네임 목록 보기 (누가 저장했는지)
- 친구 목록/관리
- 앱 내 채팅
- 카테고리/폴더 분류
- 스트릭/연속 기록
- 위젯
```

## 4. 상세 기능 명세

### 기능 1: 회원가입 (신규)

**사용자 스토리**
> "간단하게 가입하고, 친구들과 함께 사용하고 싶어"

**가입 플로우**
```
┌─────────────────────────────────┐
│         LinkPing 시작하기        │
├─────────────────────────────────┤
│                                 │
│    🔗 저장한 링크, 실천하자!     │
│                                 │
│   ┌─────────────────────────┐   │
│   │  🍎 Apple로 계속하기     │   │
│   └─────────────────────────┘   │
│                                 │
│   ┌─────────────────────────┐   │
│   │  🔵 Google로 계속하기    │   │
│   └─────────────────────────┘   │
│                                 │
│        나중에 할게요 →          │
│                                 │
└─────────────────────────────────┘
```

**프로필 설정 (로그인 후)**
```
┌─────────────────────────────────┐
│         프로필 설정             │
├─────────────────────────────────┤
│                                 │
│  닉네임                         │
│  ┌─────────────────────────┐   │
│  │ 운동하는민수              │   │
│  └─────────────────────────┘   │
│  * 다른 사용자에게 표시됩니다    │
│                                 │
│  국가                          │
│  ┌─────────────────────────┐   │
│  │ 🇰🇷 대한민국          ▼  │   │
│  └─────────────────────────┘   │
│                                 │
│   ┌─────────────────────────┐   │
│   │         완료            │   │
│   └─────────────────────────┘   │
│                                 │
└─────────────────────────────────┘
```

**입력 필드**
| 필드 | 필수 | 설명 | 예시 |
|------|------|------|------|
| 소셜 로그인 | ✅ | Google / Apple | - |
| 닉네임 | ✅ | 2-20자 | "운동하는민수" |
| 국가 | ✅ | 선택 (드롭다운) | 대한민국, United States, ... |

**비회원 모드**
```
- "나중에 할게요" 선택 시 로컬 모드
- 소셜 기능 비활성화
- 언제든 로그인하면 활성화
```

### 기능 2: 링크 등록

**입력 필드**
| 필드 | 필수 | 설명 | 예시 |
|------|------|------|------|
| URL | ✅ | 이동할 링크 | https://instagram.com/reel/xxx |
| 제목 | ✅ | 알림에 표시될 메시지 | "아침 스트레칭 하자!" |
| 시간 | ✅ | 알림 시간 | 07:00 |
| 반복 | ✅ | 반복 요일 | 매일 / 평일 / 주말 / 특정요일 |

**플로우**
```
1. + 버튼 탭 (또는 외부 앱에서 공유)
2. URL 붙여넣기 (공유 시 자동 입력)
3. 제목 입력
4. 시간 선택 (TimePicker)
5. 반복 요일 선택
6. 저장 버튼
→ 서버에 URL 해시 저장 (저장 수 카운트용)
```

### 기능 3: 알림 & 이동

**알림 구성**
```
┌─────────────────────────────────┐
│ 🔔 LinkPing              07:00  │
├─────────────────────────────────┤
│                                 │
│  아침 스트레칭 하자!             │
│  👥 12명이 같이 하는 중          │
│                                 │
│  [ 이동하기 ]    [ 나중에 ]     │
│                                 │
└─────────────────────────────────┘
```

**동작**
| 액션 | 결과 |
|------|------|
| "이동하기" 탭 | 해당 URL 앱/브라우저로 열기 |
| "나중에" 탭 | 알림 닫기 |
| 알림 스와이프 | 알림 닫기 |

### 기능 4: 링크 관리

**목록 화면 (업데이트)**
```
┌─────────────────────────────────┐
│  LinkPing        👤    [ + ]   │
├─────────────────────────────────┤
│                                 │
```

**카드 동작**
| 액션 | 결과 |
|------|------|
| 카드 탭 | 수정 화면으로 이동 |
| 토글 탭 | 알림 활성/비활성 |
| 왼쪽 스와이프 | 공유, 삭제 버튼 표시 |
| "👥 N명" 탭 | (v2) 닉네임 목록 표시 |

### 기능 5: 공유로 받기 (신규)

**사용자 스토리**
> "인스타에서 운동 영상 보다가 바로 LinkPing에 저장하고 싶어"

**플로우**
```
인스타그램/유튜브/틱톡
        │
        │ 공유 버튼 탭
        ▼
┌─────────────────┐
│   공유 대상     │
│                 │
│ 📱 LinkPing    │ ← 선택
│ 💬 카카오톡    │
│ 📨 메시지      │
└─────────────────┘
        │
        ▼
LinkPing 앱 열림 (URL 자동 입력)
        │
        ▼
제목, 시간만 설정하고 저장
```

### 기능 6: 저장 인원 표시 (신규)

**사용자 스토리**
> "이 운동 영상 인기 있구나, 나만 하는 게 아니네"

**표시 방식**
```
👥 23명이 저장함

- URL 해시 기준으로 카운트
- 실시간 X, 주기적 업데이트
- 익명 (닉네임 표시 X - v2에서)
```

**동기부여 효과**
```
- Social Proof: "다른 사람도 하네"
- 경쟁심: "나도 해야지"
- 소속감: "같이 하는 느낌"
```

### 기능 7: 친구 초대 (신규)

**사용자 스토리**
> "친구한테 이 영상 공유하고, 같이 운동하자고 하고 싶어"

**공유 메시지**
```
┌─────────────────────────────────┐
│                                 │
│  🔗 [아침 스트레칭 하자!]       │
│                                 │
│  나 이거 매일 아침 7시에        │
│  알림 받아서 하고 있어!         │
│                                 │
│  너도 같이 하자 👇              │
│  https://linkping.app/s/abc123  │
│                                 │
│  LinkPing에서 열기              │
│                                 │
└─────────────────────────────────┘
```

**플로우**
```
친구가 링크 클릭
      │
      ├─ 앱 있음 → 앱에서 열림 → 바로 저장 화면
      │
      └─ 앱 없음 → 스토어로 이동 → 설치 후 딥링크로 저장 화면
```

## 6. 수익 모델

### 무료 버전
- 링크 **3개**까지 등록 가능
- 모든 기본 기능 사용 가능 (소셜 포함)
- 목록 화면 하단 **배너 광고**

### 프리미엄 버전
| 가격 | 혜택 |
|------|------|
| $2.99/월 | 무제한 링크, 광고 제거 |
| $19.99/평생 | 무제한 링크, 광고 제거 |

### 수익 예상 (업데이트)
```
목표: 월 $1,000

소셜 기능 추가로 예상 변화:
- 바이럴 계수 증가 (친구 초대)
- 리텐션 증가 (함께 하는 느낌)
- 전환율 증가 (더 많은 링크 등록 욕구)

시나리오:
- MAU 10,000명 (소셜로 더 빠른 성장)
- 프리미엄 전환율 5%
- 평생 구매 $19.99
- 월 신규 500명 × 5% × $19.99 = $500
- 배너 광고 추가 수익: $300
- 합계: ~$800/월
```
