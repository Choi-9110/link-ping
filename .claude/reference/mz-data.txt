  일반적인 프로세스:                                    
  1. 앱에서 공유 → 웹 URL 공유 (예:                     
  linkping.app/s/abc123)                                
  2. 받는 사람이 URL 클릭                               
     ├─ 앱 있음 → 앱으로 바로 열기 (딥링크)             
     └─ 앱 없음 → 랜딩페이지 표시                       
                   ├─ 링크 미리보기                     
                   ├─ App Store / Play Store 버튼       
                   └─ 앱 설치 후 자동으로 해당 링크 저
                                                        
  필요한 것들:                                          
  구성요소: 웹 호스팅                                   
  옵션: Firebase Hosting (무료), Vercel, Netlify        
  ────────────────────────────────────────              
  구성요소: 랜딩페이지                                  
  옵션: Flutter Web / 간단한 HTML                       
  ────────────────────────────────────────              
  구성요소: 딥링크                                      
  옵션: Firebase Dynamic Links / App Links / Universal  
    Links                                               
  ────────────────────────────────────────              
  구성요소: 공유 데이터 저장                            
  옵션: Firestore (이미 사용중)

  https://linkping.app/s/{shareId}

   응응! Flutter Web으로 가능해요! 지금 프로젝트 그대로  
  웹으로 빌드하면 돼요.                                 
                                                        
  이미 있는 것:                                         
  - ✅ Flutter 프로젝트 (웹 지원됨)                     
  - ✅ Firebase 설정 (Firestore 이미 사용중)            
                                                        
  추가로 할 것:                                         
  # 1. 웹 빌드                                          
  flutter build web                                     
                                                        
  # 2. Firebase Hosting에 배포                          
  firebase deploy --only hosting                        
                                                        
  구조:                                                 
  link-ping/                    ← 지금 프로젝트         
  ├── lib/                                              
  │   └── presentation/                                 
  │       └── screens/                                  
  │           └── share_landing/   ← 랜딩페이지 추가    
  │               └── share_landing_screen.dart         
  ├── web/                      ← 이미 있음!            
  └── build/web/               ← 빌드하면 생김          
                                                        
  즉, 별도 HTML 안 만들어도 되고, 지금 프로젝트에서     
  랜딩페이지 화면 하나 만들고 Firebase Hosting에 올리면 
  끝이에요!                                             
                                                        
  비용: Firebase Hosting 무료 (월 10GB 전송량)
