```
Thank you for reviewing Linkku.

1. LOGIN: No account is required — tap "게스트로 시작" (Start as Guest) on the
   first screen to access all core features. Google/Apple sign-in is optional.

2. USER-GENERATED CONTENT (3-second proof videos): Users can record short proof
   videos shared only with people on the same alarm link.
   - Report: open any video → flag icon (top right) → submit. Reports are
     reviewed within 24 hours.
   - Block: same flag menu → "Block this user" hides all their content.
   - Videos auto-expire after 7 days.

3. SHARING: To test the share flow, create an alarm → share button → the link
   opens a web landing page → "Open in App" deep-links back with an accept dialog.

4. IN-APP PURCHASE: Premium (monthly/yearly/lifetime) removes ads and unlocks
   unlimited alarms. Guest users are asked to link an account before purchasing
   so the purchase can be restored across devices.

5. Account deletion: Settings → Account → Delete Account (in-app, per 5.1.1(v)).
```

## 10. 실서비스 결제 테스트 (Sandbox)

1. 🖱 ASC > 사용자 및 액세스 > **Sandbox 테스터** 계정 생성 (실제 미사용 이메일)
2. 실기기: 설정 > App Store > 맨 아래 **샌드박스 계정**에 로그인 (본 계정 로그아웃 불필요)
3. TestFlight 빌드에서 프리미엄 구매 → 가격에 [Environment: Sandbox] 표시 확인
4. 확인 항목: 구매 → isPremium 전환 → 광고 사라짐 / 구매 복원 동작 / **취소 후 재시도**
5. 구독 테스트 팁: Sandbox에서 월간 구독은 5분 주기로 갱신 (빠른 만료 테스트 가능)
