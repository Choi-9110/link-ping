## 프리미엄 기능
- [ ] 광고 배너 사라짐
- [ ] 링크 무제한 등록 가능
- [ ] 프리미엄 알람 소리 해금됨
- [ ] 핑 무제한 전송 가능

## 알림
- [ ] 알림 수신됨
- [ ] 알림 탭 → 링크 바로 열림 (앱만 열리면 안 됨)
- [ ] 스누즈 (3분 후) 동작
- [ ] 커스텀 소리 적용됨

## 타임피커
- [ ] 00~23시 연속 스크롤
- [ ] 11→12 넘어가면 AM→PM 자동 전환
- [ ] AM/PM 직접 돌리면 시간 ±12 자동 조정

## 추천 북마크
- [ ] 북마크 화면에 ⭐ 추천 폴더 보임
- [ ] 탭하면 추천 리스트 5개 표시
- [ ] 링크 열기 / 알람 설정 / 북마크 저장 동작

## 공지사항
- [ ] admin에서 공지 작성 → 앱 알림 화면에 표시
- [ ] 읽지 않은 공지 → 빨간 점 표시
- [ ] 공지 탭 → 읽음 처리 (빨간 점 사라짐)

## 광고

- [ ] 인증 녹화가 **후면 카메라**로 시작

- [ ] 재인증 시 내 이전 영상 사라지고 최신 1개만 남음
- [ ] 인증 폴더 안 읽음 빨간 점 → 폴더 열면 사라짐
