# TestFlight 테스트 체크리스트 (v1.0.2+3)

## 로그인
- [ ] Apple 로그인 → 프로필 설정 화면 진입
- [ ] Google 로그인 → 프로필 설정 화면 진입
- [ ] 게스트 로그인 → 홈 화면 진입

## 결제 (IAP)
- [ ] 프리미엄 화면에 상품 3개 표시 (월간/연간/평생)
- [ ] 월간 Sandbox 결제 성공
- [ ] 결제 후 isPremium 전환됨

## 프리미엄 기능
- [ ] 광고 배너 사라짐
- [ ] 링크 무제한 등록 가능
- [ ] 프리미엄 알람 소리 해금됨
- [ ] 핑 무제한 전송 가능

## 알림
- [ ] 알림 수신됨
- [ ] 알림 탭 → 링크 바로 열림 (앱만 열리면 안 됨)
- [ ] 스누즈 (3분 후) 동작
- [ ] 커스텀 소리 적용됨

## 타임피커
- [ ] 00~23시 연속 스크롤
- [ ] 11→12 넘어가면 AM→PM 자동 전환
- [ ] AM/PM 직접 돌리면 시간 ±12 자동 조정

## 추천 북마크
- [ ] 북마크 화면에 ⭐ 추천 폴더 보임
- [ ] 탭하면 추천 리스트 5개 표시
- [ ] 링크 열기 / 알람 설정 / 북마크 저장 동작

## 공지사항
- [ ] admin에서 공지 작성 → 앱 알림 화면에 표시
- [ ] 읽지 않은 공지 → 빨간 점 표시
- [ ] 공지 탭 → 읽음 처리 (빨간 점 사라짐)

## 광고
- [ ] 배너 광고 하단 노출 (무료 유저)
- [ ] 보상형 광고 재생 → 보상 지급

## 영어 UI (해외 배포)
- [ ] 폰 언어 영어 설정 → 전체 영어 표시
- [ ] 한국어 하드코딩 없음

## 기타
- [ ] 다크모드 UI 정상
- [ ] 앱 아이콘 정상
- [ ] 앱 이름 "Linkping" 표시

## App Store 스크린샷 (테스트하면서 캡쳐)

iPhone 6.7" (필수) + 6.5" (필수) — 최소 3장, 최대 10장

- [ ] **1. 홈 화면** — 링크 알람 카드들이 보이는 메인 화면
- [ ] **2. 알림 수신** — 알림 배너가 뜬 상태 (잠금화면 or 상단 배너)
- [ ] **3. 링크 추가** — 링크 등록 화면 (URL, 시간, 요일 설정)
- [ ] **4. 타임피커** — AM/PM + 00~23시 휠 피커
- [ ] **6. 추천 리스트** — 추천 링크 목록 화면
- [ ] **7. 프리미엄** — 구독 플랜 선택 화면 (월간/연간/평생)
- [ ] **8. 소리 선택** — 알람 소리 목록 (무료/프리미엄 구분)
- [ ] **9. 공유하기** — 링크 공유 화면 or 공유받은 사람 목록
- [ ] **10. 프로필/설정** — 이모지 아바타 + 설정 화면
