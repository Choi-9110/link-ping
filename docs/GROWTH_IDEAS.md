> 2026-06-12 정리. **구현 아님 — 아이디어 보관용.** 우선순위는 출시 후 지표 보고 결정.
> 관련: 펫/위젯 로드맵은 [PET_SPEC.md](./PET_SPEC.md) 참조.

## 1. iOS 공유 시트 확장 (Share Extension) ⭐ 최우선 후보

- **문제:** 지금 링크 저장 = 복사 → 앱 열기 → 붙여넣기. 핵심 행동의 마찰이 가장 큼.
- **해결:** 사파리/유튜브/인스타 공유 시트에서 "링꾸에 저장 + 시간 설정"이 바로 되게.
- **효과:** 저장 빈도 ↑ → 알림 ↑ → 리텐션 ↑. 위젯보다 임팩트 클 가능성.
- **기술:** iOS Share Extension(네이티브 타겟) + App Group으로 본앱과 데이터 공유. 위젯과 같은 인프라(App Group)를 쓰므로 **위젯 작업과 묶어서 진행하면 효율적**.

## 1.5 공유 연결 모드 옵션 (체인 공유) — 사용자 발의 2026-06-12

현재 공유 = **"모두 연결"**: 링크 하나에 참여자 전원이 한 그룹 (A→B→C ⇒ C는 A·B 다 보임).
추가 옵션으로 **"공유한 사람끼리만(체인)"**: A→B→C→D ⇒ C에겐 B(직접 준 사람)+D(직접 받은 사람)만 보임.

- 설계 방향: SharedLink 에 `visibility: 'all'|'chain'` + `rootShareId` 추가. 체인 모드는 받은 사람이 재공유할 때 **자식 공유 문서**를 만들고 rootShareId 로 묶음. "함께하는 사람" = 내가 속한 문서들의 참여자 합집합. 알람 중복 방지는 rootShareId 기준.
- 영향 범위: 공유 생성 옵션 UI / saved_users 집계 / 인증갤러리 폴더 묶음 / 딥링크 수락 dedup.
- 결정: V1은 "모두 연결" 단일 모드 (검증된 코어 유지). 체인은 1.0.1+ 후보.

## 1.6 링크 한도 vs 바이럴 루프 — ✅ 해결됨 (2026-06-13 구현)

무료 2개(+초대 보너스 1) / 프리미엄 무제한. 링크 알람 = 습관 슬롯이라 제한 타당(사용자 확정).
**구현된 절충안**: 공유 알람 수락 시 한도가 가득 차 있으면 막지 않고 **"광고 보고 추가"** 제안
(main_shell `_offerAdToAcceptShare`). 거절하면 추가 안 됨 — "알고 넘어가는" UX.
- BM 구조: 내 알람 생성 = 결제 포인트(광고 불가) / 공유 수신 = 광고 포인트 / 프리미엄 = 모두 무제한
- 출시 후 관찰: 광고 게이트에서의 이탈률(다음에 비율) — 높으면 수신 전용 +1 무료 슬롯 검토

## 2. 루틴 팩 / 큐레이션 마켓

- "아침 루틴 5링크 팩", "토익 30일 팩"처럼 **링크+시간 묶음**을 공유/설치.
- 추천 탭의 자연 확장. 크리에이터/파트너 제휴 → 어필리에이트 수익원 가능.
- 시작은 운영 큐레이션 팩 몇 개로 가볍게 → 반응 보고 유저 제작 개방.

## 3. 크리에이터 배포 링크 (B2C2C)

- 유튜버/강사가 구독자에게 "매주 화 8시 내 영상 알림" 링크를 배포.
- 크리에이터가 마케팅을 대신해주는 구조 → CAC 절감. 기존 공유링크+추천코드 인프라 재활용.
- 크리에이터용 대시보드(구독자 수·실천율)는 추후.

## 4. 그룹 챌린지 (커플 → 크루)

- 현재 1:1 공유를 N인 그룹으로: 스터디/헬스 크루가 같은 링크·시간 공유 + **그룹 스트릭**.
- 프리미엄(유료) 기능으로 적합. 그룹 단위 응원/찌르기 = 소셜 루프 강화.

## 5. 카카오톡 공유 카드 최적화

- 한국 바이럴 채널은 결국 카톡. 공유 시 **링꾸 캐릭터 + 시간이 박힌 OG 카드** 자동 생성.
- 공유 랜딩(`/s/...`)의 OG 메타를 동적 생성(Functions)하면 구현 가능.

## 6. 주간 리포트 / 스마트 시간 추천

- "이번 주 실천율 80% · 알림은 9시대가 가장 잘 지켜져요" — 이미 쌓는 통계(userStats) 재활용.
- 주 1회 리포트 푸시 = 자연스러운 리텐션 접점. 데이터 기반 시간 추천으로 확장.

### ⚡ 1.0.1 최우선 — 푸시 알림 (FCM)

응원/찌르기가 **앱이 꺼져 있으면 전달 안 됨** (FCM 미연동 — firebase_messaging 없음, APNs 미설정, Functions 트리거 없음). 인앱 종 뱃지만 실시간(Firestore 스트림). 소셜 핑의 가치는 푸시에서 나오므로 **출시 직후 첫 업데이트로 최우선**:
1. Apple 개발자센터에서 APNs 키 발급 → Firebase 콘솔 등록 (사용자 작업)
2. `firebase_messaging` 추가 + iOS push entitlement/권한 요청
3. Cloud Function: `users/{uid}/notifications` onCreate → FCM 발송
4. 토큰 저장: users/{uid}/private (전화번호처럼 비공개 위치)

### 참고 메모 (감사 중 발견한 개선 거리)
- `findReferrerByCode`가 **users 전체 컬렉션 스캔** — 유저 늘면 비용/속도 문제. referralCode 필드 저장 + 인덱스 쿼리로 교체 필요 (성장 전 필수 리팩터).
- `admin.html`(public/)은 평문 비밀번호 + 익명 로그인 구조 — 현재 미배포 상태. 다시 쓸 거면 Google 로그인 + isAdmin 체크로 재작성 후 web/로 이동.
